# LottoPro Analyse

Eine moderne Windows-Desktop-App für LOTTO 6 aus 49 mit:

- lokaler SQLite-Datenbank
- historischer Datenanalyse
- CSV-Import aus offiziellen Lotteriedownloads oder selbst erstellten Dateien
- Frequenzgrafik für jede Zahl
- Filter für Zahlensummen und gerade/ungerade Zahlen
- Generator für mehrere Tipp-Kombinationen
- CSV-Export der erzeugten Tipps

Wichtig: Die App analysiert historische Daten und organisiert Tipps. Sie kann keine zukünftigen Lotto-Ergebnisse vorhersagen und keine Gewinne garantieren.

## Voraussetzungen

- Windows 10/11
- Python 3.10 oder höher
- Tkinter / Tcl-Tk muss für Python installiert sein

## Installation

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Starten

```powershell
python lotto_app.py
```

## EXE-Build

Im Projektordner doppelklicken:

```bat
build_lotto_exe.bat
```

Die erzeugte EXE liegt danach im Ordner `dist\LottoPro.exe`.

## CSV-Format für echte Ziehungen

Ein offizieller CSV-Export kann z. B. wie folgt aufgebaut sein:

```csv
Datum;Zahl1;Zahl2;Zahl3;Zahl4;Zahl5;Zahl6
03.01.2025;4;9;17;23;35;41
10.01.2025;2;8;13;28;34;47
```

Die App akzeptiert außerdem Zeilen mit sechs Zahlen direkt, sofern sie im Bereich 1 bis 49 liegen. Kopfzeilen werden automatisch ignoriert.

## Hinweis

Die App nutzt echte historische Ziehungsergebnisse nur lokal für Statistik und Organisation. Das Tool ist ein Analyse- und Organisationsprogramm – kein System, das künftige Lotterien vorhersagt oder garantierte Gewinne anbietet.
