# python-version-launcher

Python Version Manager – wähle zwischen Python 3.8, 3.11 und 3.14 für deine Tools.

## FAQ Studio

Dieses Repository enthält zusätzlich einen einfach bedienbaren FAQ-Generator für Windows, macOS und Linux. Er läuft lokal mit Python/Tkinter und erstellt professionelle FAQ-Seiten.

### Schnellstart

```bash
python faq_generator.py
```

Unter Windows kannst du auch `py faq_generator.py` verwenden. Für den optionalen Excel-Import installiere einmalig:

```bash
python -m pip install -r requirements-faq.txt
```

CSV-Import, Antwortvorlagen, KI-Prompt-Erstellung und HTML-/Markdown-/CSV-/JSON-Export funktionieren ohne weitere Pakete. Ausführliche Bedienung und unterstützte Importspalten findest du in [FAQ_STUDIO.md](FAQ_STUDIO.md).
