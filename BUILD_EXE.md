# Build der Windows-EXE

Im Windows-Projektordner `build_lotto_exe.bat` doppelklicken. Das Skript erstellt bei Bedarf eine lokale virtuelle Python-Umgebung, installiert PyInstaller und baut die App.

Die fertige Anwendung wird unter `dist\LottoPro.exe` abgelegt. Beim ersten Build braucht der Rechner Internetzugang, um PyInstaller zu installieren.
